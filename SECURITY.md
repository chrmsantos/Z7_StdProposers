# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| 8.10.x   | :white_check_mark: |
| 8.9.x    | :white_check_mark: |
| < 8.9    | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Z7_StdProposers, please report it by opening an issue on the [GitHub repository](https://github.com/chrmsantos/Z7_StdProposers/issues).

We take security reports seriously and will respond as quickly as possible. Please include:

- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Your assessment of the potential impact.

We appreciate responsible disclosure and will acknowledge your contribution.
